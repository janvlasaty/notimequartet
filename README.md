# Notime Quartet

Prague-based string quartet website built with React, TypeScript, and Vite.

## Musicians

- **Tadeáš Kříž** - 1st violin
- **Jan Vlasatý** - 2nd violin
- **Linda Tomášková** - viola
- **Daniela Nečasová** - violoncello

## Features

- Responsive design
- Internationalization (Czech default, English)
- Sections for:
  - Musicians profiles
  - Upcoming concerts
  - Photo and video gallery
  - Repertoire
- GitHub Pages deployment

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch.

Visit: https://janvlasaty.github.io/notimequartet/

## Tech Stack

- React 19
- TypeScript 6
- Vite 8
- react-i18next for internationalization
